# 🤖 04-gen-ai: Generative AI Cookbook

This directory is your hands-on learning space for everything related to **Generative AI**. It includes foundational concepts, models, practical experiments, and deployment-ready code — structured in a beginner-friendly way and powered by Python + Hugging Face + PyTorch.
