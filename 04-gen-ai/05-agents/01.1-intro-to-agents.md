# AI Agents

## 📌 What Are AI Agents?

- AI agents are **autonomous or semi-autonomous systems** that perceive, reason, and act to accomplish tasks.
- They differ from traditional prompt-based models by using **multi-step workflows** that involve planning, tool usage, and reflection.
- AI agents can be classified into:
  - **Non-agentic**: One-shot tasks like asking ChatGPT a question.
  - **Agentic**: Multi-step, iterative workflows (e.g., research → plan → execute → revise).
  - **Autonomous AI**: Fully self-revising agents that act without human input (still in development).

--- 

## 🧩 Core Design Patterns of AI Agents

1. **Reflection**
   - Agents **review and improve** their own outputs.
   - Can involve another agent critiquing and refining the response.

2. **Tool Use**
   - Agents use **external APIs or tools** (e.g., calculators, web search).
   - Allows access to real-time or domain-specific data.

3. **Planning and Reasoning**
   - Break tasks into steps using workflows and goal decomposition.
   - Enables **multi-hop** logic and contextual tool selection.

4. **Multi-Agent Systems**
   - Different agents have **specialized roles** and communicate.
   - Mimics human teamwork, often yielding better results.

---

## 🧠 Multi-Agent Architectures

- **Single-Agent** systems: Combine task, model, and tools (T.A.M.T).
- **Sequential**: Each agent performs a step in order (e.g., OCR → summarize → store).
- **Hierarchical**: A manager agent delegates tasks to sub-agents.
- **Parallel**: Agents work simultaneously on different parts of a task.
- **Hybrid**: Mix of hierarchical and sequential coordination.
- **Asynchronous**: Agents operate independently over time (e.g., security monitoring).
- **Floats**: Complex multi-agent systems connected in layers.

## 🧱 ReACT: Reasoning + Action

> ReACT is a framework that merges **thoughtful planning (reasoning)** with **external tool use (action)**.

### 🔄 How It Works:
1. **Initial Thought**: The model explains what it plans to do.
2. **Action**: Executes a tool-based task (e.g., search Wikipedia).
3. **Observation**: Receives the result of that action.
4. **Refined Thought**: Updates its reasoning.
5. **Final Answer**: Produces a confident, evidence-backed output.

### 🧪 Example:
> Q: *"How old is the US President?"*

- Thought: Search birthdate of Joe Biden.
- Action: Wikipedia search.
- Observation: Born Nov 20, 1942.
- Final: 80 years old in 2023

---

## ⚙️ ReACT in LangChain

- **Prompt Template**: Guides the model with examples (reasoning, action, observation).
- **Tools**: Like WikipediaSearchTool, calculator, etc.
- **Scratchpad**: Tracks step history.
- **Output Parser**: Extracts thoughts/actions from model output.

```python
agent = ReActAgent(tools=[WikipediaSearchTool()], prompt=react_prompt)
response = agent.run("How old is the President of the United States?")
```

- Benefits:
  - Higher accuracy
  - Lower hallucination
  - Greater transparency in thought process

---

## ⚠️ Challenges of ReACT

- High token usage (due to multiple steps).
- Works best with **large models** (e.g., GPT-4).
- Requires thoughtful **prompt engineering**.
- Integrating external tools can add complexity.
