# 📚 02-LLMs: Exploring Large Language Models

This module is focused on foundational and practical concepts around **Large Language Models (LLMs)**. It contains structured notes and Jupyter notebooks that explore how LLMs work, how to interact with them via prompting, and how to fine-tune models such as LLaMA 2.

---

## 📁 Folder Structure

```md
02-llms/
├── notebooks/
│ └── fine-tuning-Llama-2.ipynb       # Hands-on fine-tuning notebook for LLaMA 2
├── 01-intro-to-llm.md               # Introduction to LLMs and how they work
├── 02-prompt-engineering.md         # Notes on prompt crafting, tips, and strategies
├── 03-fine-tuning-llm.md             # Guide to fine-tuning LLMs (paired with notebook)
└── README.md
```

## 🧠 Contents Overview

### 1. Introduction to LLMs (`01-intro-to-llm.md`)
- What are LLMs?
- Training vs Inference

- Why fine-tune an LLM?
