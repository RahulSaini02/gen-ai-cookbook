# 🧠 Deep Learning

## Neural Networks

> **What is a Neural Network?**
>
>Neural networks are a type of machine learning model inspired by the human brain, consisting of interconnected nodes (neurons) that process data and learn patterns. They are used for various tasks like pattern recognition, decision-making, and prediction. 

Anatomy of Neural Networks:
- Input Layer
- Hidden Layer(s)
- Output Layer

> **Note:** "Patterns" is an arbitrary word for **embeddings**, **weights**, **feature representation**, **feature vectors**

### Types of Learning

1. **Supervised Learning** - Data, with labels
2. **Unsupervised Learning** - Data
3. **Transfer Learning** - One model transfer what it learned to another model.
